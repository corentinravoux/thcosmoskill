# Methods index

Scope: where each calculational method of theoretical cosmology is treated
in the suite. A method used in several domains has one home section; the
others point to it. First version, written at the first milestone (plan v2,
stage 4): a method with a built home names its section (`skill/file#key`);
the others name their planned home.
