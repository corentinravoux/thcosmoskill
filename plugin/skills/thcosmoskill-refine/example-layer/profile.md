# Profile

Example layer of the thcosmoskill package: a fictional researcher working on
inflationary model building. It shows the shape, size and labelling of a
good layer; copy the pattern, not the content.

home-domains: thcosmo-inflation, thcosmo-primordial-correlators
conventions: metric signature (−,+,+,+); reduced Planck mass; Hubble-flow slow-roll parameters

I build and test single- and multi-field inflation models and compute their
primordial correlators. Late-time cosmology enters my work only through the
bounds it puts on n_s, r and f_NL.
