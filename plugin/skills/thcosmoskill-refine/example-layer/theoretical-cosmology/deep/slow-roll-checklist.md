# Slow-roll predictions: what I check

Scope: the checks this researcher runs on a slow-roll prediction before
quoting it; a personal dossier, not package content.
Snapshot: 2026-10-30.

## Checks
<!-- key: checks -->

- The definition of the slow-roll parameters (Hubble-flow or potential)
  and the order of the prediction; the lectures arXiv:0907.5424 set out
  both definitions.
- The pivot scale and the e-fold number assumed, and how reheating fixes
  it.
- The package's conventions section on the early universe:
  `theoretical-cosmology/conventions#early-universe`.

## Not verified

- My own rule of thumb on how far the e-fold number can move with
  reheating is from experience, not from a source.
